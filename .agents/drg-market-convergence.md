# DRG Market Convergence Agent

**Purpose:** Validate new MVP software against existing professional services ecosystem

**Trigger Phrases:**
- "Analyze convergence between [software] and [service]"
- "Will [product] cannibalize [existing business]?"
- "How do we integrate MVP with labs?"
- "Market analysis for [new product + existing service]"

**Inputs Expected:**
```
Existing Business: [URL/description]
  - Services offered
  - Pricing (per service)
  - Annual revenue (if known)
  - Geographic reach
  - Client roster

New MVP/Software:
  - Name
  - Price point
  - Target users
  - Core features
  - Timeline to launch
```

**Outputs Delivered:**
- ✅ Convergence analysis (market fit, synergies, risks)
- ✅ Revenue model (software + referral commissions)
- ✅ Escalation workflow (DIY → professional services)
- ✅ Competitive positioning
- ✅ Brand strategy (sub-brand naming, messaging)
- ✅ Risk mitigation plan
- ✅ Go-to-market timeline (4–6 months)
- ✅ Multilingual artifact (PT-BR, EN, DE)

**Success Criteria:**
- Zero cannibalization identified (software users ≠ service users)
- Revenue synergies quantified (€100k–200k Year 1 from referrals)
- Brand positioning clear (prevents confusion between DIY and professional)
- Escalation path defined (seamless upgrade from software to services)

---

**Reusable For:**
- New DRG software products (analyzing fit with labs)
- Partner integrations (third-party software → DRG services)
- Market expansion (new geographies, new user segments)
- Business model validation (SaaS + services hybrids)
